プライバシーポリシー

対象アプリ: Logos - AI音声メモ＆AI変換 / 最終更新日: 2026年3月18日

本ポリシーは、Logos - AI音声メモ＆AI変換（以下「本アプリ」）におけるユーザー情報の取扱いを定めるものです。実装されている機能（メモ保存、iCloud同期、AI変換、音声文字起こし、サブスクリプション）に対応した内容を記載しています。

1. 取得・利用する情報

本アプリでは、機能提供のために以下の情報を取り扱います。

・メモ本文、フォルダ情報、変換設定（アプリ内の保存・表示・編集のため）

・録音した音声データ（文字起こし実行時のみ）

・AI変換に送信するテキスト（ユーザーが変換操作を行った場合のみ）

・認証情報（Appleサインイン経由の認証結果、Firebase Authentication のUID等）

・課金/プラン情報（StoreKit取引情報、レシート情報、チケット残高、プラン状態）

・端末/アプリ識別子（アプリ内で生成するインストールID等。Keychain / UserDefaults に保持）

2. ローカル保存とiCloud同期

メモ、フォルダ、変換設定は、端末内のアプリ領域（Application Support）に保存されます。

本アプリは、利用可能な場合に iCloud コンテナを用いた同期を行う実装を含みます。iCloud同期の実行可否は、ユーザーのAppleアカウント状態・端末設定・環境に依存します。

ローカル保存ファイルには iOS のファイル保護（completeUntilFirstUserAuthentication）を適用する実装を行っています。

3. サードパーティAI（OpenAI）への音声データ送信

アプリ内でユーザーが明示的に文字起こし機能を実行した場合にのみ、以下のデータが外部のサードパーティAIサービスに送信されます。

・送信先のサービス: OpenAI API (Whisper)

・送信されるデータ: 録音された音声データ（WAV形式等）

・利用目的: 高精度な音声文字起こし機能を提供するため

・データの保護と取扱い: 音声データは Firebase Cloud Functions を経由して安全に送信されます。API経由で送信されたデータは本機能の提供目的にのみ使用され、OpenAIのAIモデルの学習（トレーニング）には使用されません。OpenAIは本アプリと同等以上のデータ保護水準を提供しています。

4. サードパーティAI（Google Gemini）へのテキストデータ送信

アプリ内でユーザーが明示的にAI変換機能を実行した場合にのみ、以下のデータが外部のサードパーティAIサービスに送信されます。

・送信先のサービス: Google Gemini API

・送信されるデータ: 変換対象として指定されたテキストデータ、およびユーザーの指示（プロンプト）

・利用目的: 文章の要約、構造化、翻訳などのAIテキスト変換機能を提供するため

・データの保護と取扱い: テキストデータは Firebase Cloud Functions を経由して安全に送信されます。API経由で送信されたデータは本機能の提供目的にのみ使用され、Googleは本アプリと同等以上のデータ保護水準を提供しています。

5. 認証・セキュリティ対策

本アプリは、Appleサインインと Firebase Authentication を利用して認証を行います。

Cloud Functions呼び出し時には Firebase App Check を利用し、不正利用の抑止を図っています。

6. 課金・チケット管理に関する情報

本アプリは App Store サブスクリプション（StoreKit）を利用し、レシート検証やプラン/チケット状態の同期のために Firebase Cloud Functions / Firestore を利用します。

サーバー側には、課金状態・チケット残高・検証日時・プラン状態等の管理情報が保存される場合があります。

課金処理そのものは Apple により実施され、決済情報（クレジットカード番号等）を当方が直接取得することはありません。

7. 利用目的

取得・利用する情報は、以下の目的のために利用します。

・メモ機能、音声文字起こし、AI変換等の提供

・認証状態の維持、利用制限の適用、不正利用対策

・サブスクリプション/チケット管理、購入復元、サポート対応

・障害対応および品質改善（エラー内容、利用状況の把握）

8. 第三者提供・外部サービス

本アプリは、機能提供のため、以下の外部サービスを利用します。これらのサードパーティ事業者は、本プライバシーポリシーと同等またはそれ以上の個人データ保護水準を満たしていることを確認しています。

・Apple（Sign in with Apple / App Store / StoreKit）

・Google Firebase（Authentication, Cloud Functions, Firestore, App Check）

・Google Gemini API（AI文章変換）

・OpenAI API（音声文字起こし）

法令に基づく場合を除き、上記目的以外でユーザー情報を本人の同意なく第三者へ販売または提供することはありません。

9. 保存期間と削除

端末内およびiCloud上のメモ等のデータは、ユーザーが削除するまで保持される場合があります。

サーバー側の認証・課金管理情報は、サービス運営上必要な期間保持される場合があります。

アプリのアンインストール、端末操作、iCloud設定変更等により一部データが削除される場合がありますが、外部サービス側の保持は各社ポリシーに従います。

10. ユーザーの選択と同意

ユーザーは、マイク権限、Appleサインイン、App Storeサブスクリプション、iCloud設定等を端末または各サービスの設定画面から管理できます。

サードパーティAIサービスへのデータの送信は、アプリ内での事前同意を得た上で、ユーザー自身が「文字起こし」や「AI変換」のボタンを操作した時にのみ実行されます。バックグラウンドで自動的に送信されることはありません。

11. ポリシーの変更

本ポリシーは、法令・サービス仕様・実装変更等に応じて改定する場合があります。改定後は本アプリ内に掲載した時点または別途定めた効力発生日から適用されます。
